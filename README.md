# 💍 Jagoda & Pavel Countdown

A playful, mobile-friendly countdown to **May 28, 2028, at midnight (Vilnius time)**.

## Run locally

Open `index.html` in any modern browser. No installation or dependencies needed.

## Publish free with GitHub Pages

1. Create a new public GitHub repository, e.g. `jagoda-pavel-countdown`.
2. Upload `index.html`, `style.css`, and `script.js` to the repository root (or push them with Git).
3. In the repository, open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**, select `main` and `/ (root)`, then **Save**.
5. Once GitHub deploys the site, its URL will be `https://YOUR_USERNAME.github.io/jagoda-pavel-countdown/` (substitute your GitHub username and repository name).

## Customize

- Change the text in `index.html`.
- Change colors and layout in `style.css`.
- Change the target date in `script.js`. The current target uses an explicit `+03:00` offset, which is correct for Vilnius on May 28, 2028.
